CORRECTION DE L'OUVERTURE DES ESPACES RESTAURANT ET HOTEL

Fichiers à remplacer à la racine du dépôt GitHub :
- dashboard.js
- zrestaurant-portal-bridge.js
- zguard.js
- zrestaurant-restaurant.html
- compte.html

Cause corrigée : le tableau de bord ouvrait le même fichier pour Restaurant et Hôtel sans transmettre le pôle demandé. Le pont Supabase pouvait alors sélectionner le dernier établissement configuré. La correction transmet ?portal=restaurant ou ?portal=hotel et recherche l'organisation correspondante dans rg_organizations. Elle prend aussi en charge les anciens comptes restaurant/hôtel dont organization_id manque dans les métadonnées, si l'organisation existe bien dans Supabase.

Après remplacement :
1. Publier les 5 fichiers à la racine du dépôt GitHub, en remplaçant les anciens.
2. Attendre la publication GitHub Pages.
3. Sur Android, fermer l'onglet du site puis le rouvrir. Si l'ancien écran persiste, vider le cache du site ou ouvrir une fenêtre privée.
4. Tester séparément les boutons Ouvrir Restaurant et Ouvrir Hôtel.

Aucune table ni donnée Supabase n'est modifiée par cette correction. Le test a porté sur la cohérence des routes et la syntaxe JavaScript ; le parcours doit encore être confirmé sur le compte réel.
